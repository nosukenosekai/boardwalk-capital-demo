# 孫正義式 AI活用法 — コマンド集

孫正義氏が株主総会・講演で公にしてきた AI の使い方をもとにした、6本のスラッシュコマンド。
貫いている原則は1つ: **AIに答えを出させず、意見を割らせる。決めるのは自分。**

## コマンド一覧

| コマンド | 用途 |
|---|---|
| `/son-debate [課題]` | 天才3人を設定し、目の前でディベートさせる（全ての土台） |
| `/son-angle` | 議論が丸く収まりかけたら「角度を変えろ」と刺す（何度でも可） |
| `/son-referee` | 自分は審判席へ。合意まで走らせ、①合意点 ②係争点 ③自分が決めること に3分類 |
| `/son-review [議論内容]` | 会議・ミーティングの内容をそのまま貼り、見落とした前提3つ＋不在者の視点1つ |
| `/son-blueprint [アイデア]` | 粗い思いつきを、1ステップずつ確認しながら設計図まで詰める |
| `/son-talk [テーマ]` | 結論を出さない対話時間（週末1〜2時間用）。思考の健康診断 |

## 基本の流れ

1. 決めきれない案件を1つ選び、二択・三択レベルまで具体化する
   - ❌「売上を伸ばすには」 → ⭕「来月のイベントで価格を据え置くか2割上げるか」
2. `/son-debate` で3人を揉めさせる
3. 浅くなったら `/son-angle` を刺す（1回だけでも効く）
4. `/son-referee` で論点を3分類させ、「自分が決めること」だけに時間を使う

## プリセット対立軸

3人の設定を毎回考えるのは続かないので、頻出の対立軸をあらかじめ用意しておく。
Boardwalk Capital の業務（アドバイザリー・インキュベーション・投資）向けのセット:

| 軸 | A | B | C |
|---|---|---|---|
| 投資判断 | 攻めの投資家（強気・拡大志向） | リスク管理・財務（石橋を叩く慎重派） | 起業家/現場（実行の実務家） |
| 事業判断 | 売る側（営業・マーケ） | 作る側（開発・オペレーション） | 顧客（初めて使う人） |
| 戦略 | 短期の数字 | 長期のブランド | 実行可能性 |
| プロダクト | コスト | 品質 | スピード |

必要に応じてこの表に足していく。

## 使うときの3つの注意（記事より）

1. **3人の設定は使い回す** — 毎回ゼロから考えると3日で使わなくなる
2. **課題を抽象的に書かない** — 具体的な二択まで絞って初めて意見が割れる
3. **AIの結論をそのまま採用しない** — 割れた論点を受け取って、決めるのは自分
